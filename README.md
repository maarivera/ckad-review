# ckad-review

Interactive Kubernetes certification study plan and reviewer, in the style of killer.sh.

Open `index.html` in a browser. It is a single self-contained page with no dependencies, and your progress is saved in the browser.

- **Dashboard:** exam countdown, plan progress, best mock score, quiz accuracy and per-domain readiness
- **Study Plan:** 6 weeks, 36 days of checklist tasks linked to kubernetes.io docs
- **Reviewer:** timed mock exams and quizzes
